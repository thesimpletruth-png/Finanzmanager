# UI & DPI Layout Check

1. Prüfe die genannte Form- oder Dialog-Datei anhand der UI- und WinForms-Richtlinien des Projekts.
2. Kontrolliere gezielt:
   - Werden TableLayoutPanel und Dock sauber genutzt?
   - Stimmt die Dock-Reihenfolge?
   - Ist das Fenster bei Bedarf größenveränderbar?
3. Behebe Layout-Probleme oder liste sie auf.
